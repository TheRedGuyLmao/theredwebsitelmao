# Чарник ИАБ — как включить вход и хранение листов

Где что лежит:

```
seek_and_destroy/sheet/index.html   страница
seek_and_destroy/sheet/app.js       создание персонажа, лист игрока, панель мастера
seek_and_destroy/sheet/rules.js     ПРАВИЛА: планеты, вера, навыки, очки. Меняйте здесь.
worker/index.js                     Worker сайта: отправляет запросы /seek_and_destroy/sheet/api/... на сервер
worker/sheet-api.js                 сервер чарника: хранит листы и проверяет, кто вошёл
wrangler.jsonc                      настройки Worker (имя, хранилище, какие адреса идут на сервер)
.assetsignore                       файлы, которые сайт не отдаёт посетителям
```

Сайт theredwebsite.com работает как Cloudflare Worker: файлы из репозитория отдаются как раньше,
а Worker запускается только для адресов `/seek_and_destroy/sheet/api/...`.

Пока сервер не настроен, страница работает в демо-режиме: всё хранится в браузере,
вверху есть переключатель «Игрок / Мастер».

Вход делает **Cloudflare Access** (бесплатно до 50 человек). Игрок открывает ссылку, вводит почту,
получает код и попадает на свой лист. Паролей нет. Мастер — тот, чья почта указана в `ADMIN_EMAILS`.
Листы лежат в **Cloudflare KV**.

## Порядок важен

Сначала шаги 1–2, и только потом отправляйте коммит в GitHub (push). Если отправить раньше,
сборка на Cloudflare упадёт, но сайт не сломается: останется работать прошлая версия.

## 1. Имя Worker

Cloudflare → **Workers & Pages** → найдите Worker сайта. Его имя должно совпадать с `"name"`
в `wrangler.jsonc` (сейчас там `theredwebsitelmao`). Если имя другое — поправьте в файле.

## 2. Хранилище листов (KV)

1. **Storage & Databases** → **Workers KV** → **Create** → имя, например `iab-sheets`.
2. Скопируйте его **ID** и вставьте в `wrangler.jsonc` вместо `ВСТАВЬТЕ_ID_ХРАНИЛИЩА_KV`.

## 3. Отправить в GitHub

Закоммитьте и отправьте (push). Cloudflare сам соберёт и выложит новую версию —
проверить можно в Worker → **Deployments**.

## 4. Вход (Cloudflare Access)

1. **Zero Trust** (в меню слева) → при первом входе выберите имя команды и бесплатный план.
2. **Access** → **Applications** → **Add an application** → **Self-hosted**.
   - Домен: `theredwebsite.com`, путь (**Path**): `seek_and_destroy/sheet`.
     **Указывайте путь обязательно**, иначе вход потребуется на весь сайт.
3. **Policy**: Action **Allow**, правило **Emails** — почты игроков и ваша.
4. Способ входа: **One-time PIN** (код на почту) — включён по умолчанию.
5. Сохраните, откройте приложение и скопируйте **Application Audience (AUD) Tag**.
6. Имя команды видно в **Settings** → **Custom Pages**: `ваша-команда.cloudflareaccess.com`.

## 5. Переменные

Worker → **Settings** → **Variables and Secrets** → **Add**, тип **Secret** (почты не попадут в публичный репозиторий):

| Имя | Значение |
|---|---|
| `ADMIN_EMAILS` | ваша почта (несколько — через запятую) |
| `TEAM_DOMAIN` | `ваша-команда.cloudflareaccess.com` |
| `POLICY_AUD` | AUD Tag из шага 4 |

Секреты применяются сразу, пересобирать ничего не нужно.

## Проверка

Откройте `https://theredwebsite.com/seek_and_destroy/sheet/`. Должна появиться страница входа Cloudflare,
после кода — ваш лист или список игроков (если вы мастер). Переключателя «Игрок / Мастер» быть не должно:
если он есть, значит сервер не отвечает — смотрите Worker → **Logs**.

## Новый игрок

Zero Trust → **Access** → **Applications** → ваше приложение → **Policies** → добавьте почту игрока
в правило **Emails** и отправьте ему ссылку. Его лист появится у вас в списке, как только он войдёт.
Убрать игрока — удалить почту из правила (лист останется, его можно удалить в панели мастера).

## Проверка на компьютере

Нужен Node.js. Создайте в корне репозитория файл `.dev.vars` (он в `.gitignore`):

```
DEV_EMAIL=you@test.se
ADMIN_EMAILS=you@test.se
```

и запустите `npx wrangler dev`. `DEV_EMAIL` пускает без входа. **Никогда не задавайте его на сайте.**
